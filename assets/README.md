# Brand assets

The amber D/arrow mark, wordmark treatment and social cards were created for this rebuild. The palette follows the Daclify V2 CIQ/MIQ foundations. Social cards are generated from localized homepage copy with `npm run assets:social`; review and regenerate them when that copy changes.

Inter is distributed by @fontsource-variable/inter 5.3.0 under the SIL Open Font License. Builds and exports include the package license. Latin and Latin Extended subsets cover English, Spanish and Polish. The website loads no third-party font or tracking service.
